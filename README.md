# kadai02_janken_rich
じゃんけんアプリリッチver

じゃんけん甲子園という自作ゲームを作成しました。
普段は3回裏までで「テキーラを賭けて勝つごとに相手に一杯飲ませる」というルールでやってるのですが、ゲーム版では賭博要素を持たせるために連続で勝つと倍々に獲得金額が増えていく仕様にしました。

（1）制作サイトタイトル
 ・じゃんけん甲子園
（2）制作サイトの説明（40文字程度）
 ・甲子園を模したじゃんけん賭博です。
（3）工夫した点・こだわった点
工夫：CSSはAIに丸投げしましたが、色やデザインを野球みたいになるようにしました。
こだわり：ネタ要素を強めにしました。連続で勝ったら敵を煽るようにしたり、敢えて借金できるようにして「いくら借金増えるんだ、、、」というハラハラ感を手軽に味わえるようにしました。
※画像はめっちゃ負けた時の金額と煽られ文句です。かなりうざくて好きです笑
